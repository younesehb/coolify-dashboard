# Launchpad

A launcher for everything deployed on one Coolify instance. Used by the person who runs the server to find an app and open it, see what is down, and jump to its Coolify page or repo.

- Mode: Operate. One task: find a resource and open it.
- Data: read-only from the Coolify API (applications, services, projects). Nothing invented; empty fields stay empty.
- Users: one operator, desktop first, phone when checking on the go.
