# Design — Launchpad

An iPhone / iPad-style home screen in liquid glass, in the spirit of home-server dashboards: a launcher first, a control panel second.

- Wallpaper: full-bleed landscape (`public/wallpapers/{beach,lake,dunes}.webp`, generated, original), cycled from the dock and remembered per browser. A top/bottom scrim keeps labels readable.
- Liquid glass: widgets and the search bar use React Bits `GlassSurface` (SVG displacement refraction in Chromium, WebGL refraction sampling the wallpaper `<img>` in Safari/Firefox, frosted fallback elsewhere). Tint is forced light (`color-scheme: light`) so the glass never turns murky.
- CSS glass: `.glass` in `src/index.css` — frosted backdrop (blur 26px, saturate 175%), lit top edge, soft drop, specular sheen. `.glass-dark` is the denser variant for menus, search, toasts and tooltips (blur 40px, ~82% opaque) so text over busy icons stays legible. Tokens in `src/tokens.css`.
- Layout: greeting → three widgets (Health, Instance, Needs attention) with captions under them → icon grid → Search ⌘K pill → dock.
- Icons: iOS squircles (23% radius). Real logos sit on a white tile; missing logos get a hue-from-name gradient monogram. Stopped apps are dimmed with a red badge; unhealthy/degraded get an amber badge.
- Type: system SF stack (Inter fallback). White with a soft shadow on the wallpaper.
- Status colours are the only accents: green running, amber unhealthy/degraded, red stopped.
- Interaction: click opens the app; right-click or long-press opens the peek card (status, last update, Open/Coolify/Repo/Copy, extra domains, Redeploy/Restart/Stop/Start with tap-again confirmation behind ACTIONS_PASSWORD, rename/icon, hide, remove from folder). Actions show an iOS download-style ring on the icon until Coolify reports the deployment finished. Folders: hold an app over another icon's centre to make a folder (or join one); folders open as a frosted panel with an editable title; drag an app outside to take it out; a folder with one app left dissolves. "Group by project" in Customise builds folders from Coolify projects. ⌘K or / opens Spotlight-style search (↵ open, ⌘↵ manage).
- Dynamism: sort bar (My order, A–Z, Status, Recent, Project) re-flows icons with spring FLIP animations (motion `layout`); live search filters the grid as you type; icons drag directly (dnd-kit; mouse starts after 6px so clicks still open apps, touch after a 0.2s hold so swipes still scroll); other icons jiggle while one is lifted, the empty slot shows a faint ghost, and a drop saves as "My order" (switching the sort if needed); status changes between refreshes pulse the icon and show a toast; counts roll; wallpaper crossfades.
- Dock: React Bits `Dock` with macOS magnification, labels, a red badge on Coolify for apps needing attention, and a wallpaper menu.
- Customise panel (dock, ⌘,): wallpaper presets/upload/URL and dimming, glass blur and frost, name and greeting, search bar, each widget, dock and magnification, icon size, labels, stopped apps, services, sort, refresh interval, hidden/renamed apps, export/import/reset. Per-app rename, custom icon and hide from the icon's context menu. All saved per browser in localStorage (`launchpad.settings.v1`).
- Motion: icons rise in once on load; icon and dock hover use a light iOS spring (intentional: it mirrors iOS icon motion). Reduced motion collapses all of it.
